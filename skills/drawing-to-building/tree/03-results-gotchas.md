## Results / gotchas
- housePlan1: `depth\measured_turn.png` (user: "much better"), `tex\drawn_turn2.png` (row 1 elevations only, row 2 + angled sketch with windows).
- The angled view's roof hatching partly lands on the long wall's top (the sketch's roof is steeper than the model's). Elevation outlines are thin; most detail comes from the angled sketch, so draw details (windows, doors) on the elevations too.

- Page 2 (10-12), `scenefit\page2\geo_turn.png` rows A kA B kB C D kD: hand shapes (`geo\shapes.json` -> flat colour -> Hunyuan mv) give clean blockouts true to the outline. Kontext repaints add surface detail (windows, shingles) but the unseen sides crumple (kA), and Kontext can change WHAT the object is (booth kD came out a 3-storey house). Use Kontext views only after checking they still show the same object; the hand-shape route is the dependable one.
- Kontext stall: a run can freeze mid-steps (spire_two: steps 1-3 ~10 s, step 4 25 min at 100% GPU). If a step takes over ~2 min, kill it and move on.
- turn_view.py lives in `Documents\Tools\Hunyuan3D-2\`; give it a Windows absolute out path (a relative one landed somewhere else).

- TRELLIS v1 (10-12, `scenefit\page2	rellis_turn.png`, run script `page2	rellis
un.sh`): ~35 s and ~10 GB VRAM per object. On raw pencil cut-outs the hatching turns into sticks, legs and open frames (candy_cut, tower_cut), and a thin booth from two views collapsed to a slab. On a clean shaded image (Kontext candy_front) it gave the best single-image house of all, with windows on every side. So feed TRELLIS clean images (Kontext or flat-colour views), never the raw sketch. Untested yet: TRELLIS on geo\colour flat views.

- Voxel route (10-12, VoxelBench idea, no GPU): `scenefit\page2\vox\vox_candy.py` places blocks by rule from the drawings (walls, timber posts, windows, ogee roof by a half-width curve, chimneys), builds a face-culled mesh with one material per colour, exports GLB and renders a Workbench turntable. ~2.2k blocks, 4k faces, seconds. Clean retro look; good for background props.
- Mix route (10-12): base model (voxels or hand shapes) -> `page2/vox/views4.py` renders front/left/back/right (ortho, flat, white, 512 px) -> Hunyuan mv (`img2shape_mv.py out.glb front= left= back= right=`), 156-216 s each, peak 6.0 GB, 20k faces. Result (`page2/mix_turn.png`): the mesh copies the base almost exactly, voxel steps included; tower spikes merge into a frill, the booth arch gets shallower. So the mix = a clean single 20k mesh of the base, NOT added detail. For detail the four views must carry it (paint over the views, or Kontext them consistently) before Hunyuan.
- Splat route (10-12, Dreams-style, CPU ~1 min): `page2/sdf/splat.py <mesh.glb> <front.png> <right.png> <out.png>` covers the mesh with oriented brush strokes coloured from the painted front/side images, one light, painter sort. On kA.glb it reads as a hand-painted model; tight (45k strokes) keeps windows, loose (9k) is sketchier. Good for impostor cards and backgrounds. SDF shell blend: `page2/sdf/shell.py <base> <detail> <out_prefix> [t list]`. Result 10-12 (`page2/sdf/shell_turn.png`, CPU 11 min at pitch 0.008, ~300k faces, decimate after): the blend keeps the base silhouette (straight walls, all 4 chimneys) and takes the detail mesh's windows/trim/roof tiles; t=0.02 = mostly base, 0.04 = best middle, 0.08 lets the detail's warped back wall through. Side walls stay clean where the detail was wrong. Splats 10-12 with Kontext-painted sides (`sdf/splat3_*.png`): white gaps where a view's outline misses the mesh are fixed in splat.py by falling back to the other view's colour. Gotchas: the one shared prompt ("warm colours") made all 4 buildings the same yellow/red, so give each building its own palette; Kontext turned the booth into a gothic house. Painting sides for splats: `page2/sdf/pair.py join` front+side on one canvas -> Kontext -> `split` (`sdf/paint_sides.sh`). User 10-12 on the painted-side splats: "this is exaclty what i wanted so far", "the front is real good too" (front view holds the drawing best).

- 2026-10-12 vox/mix/lines turntable: `scenefit/page2/vox_mix_lines_turn.png` (turn_view.py n=6 size=240; candy, tower, spire, booth x vox/mix/lines). Vox is blocky, mix adds form, lines carries the most carved detail (roof tiles, spire ornament, window frames); mix and lines share the silhouette.
