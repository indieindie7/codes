# gore_dying: U2Gore's hit zones and dying phase (GoreDying) on Sanctuary. The first merc dies the
# stock way and teaches its clips ("U2Gore: learned ... death clip / hit clip"); the next ones take a
# killing hit in a chosen zone (set GoreDying ShootZone) and lie dying for a few seconds (chest:
# twitching, belly/leg: dragging along the floor, neck: a pumping fountain). Results: "U2Gore:"
# lines (survey, zone, learned, dying, dies) in Unreal2.log and the shots.
background
map M08A1?Mutator=U2TestHub.HubMutator,U2Gore.GoreMutator
waitcontrol 180
wait 3
console BeMyMonkey
console god
console set GoreDying bLog True
console set GoreDying DyingChance 1
console hub tp -730 5000 6530
wait 1
turn -35 0 0.4
wait 0.5
# 1: teach. A non-lethal hit (hit clip), then the kill (death clip)
spawn U2Pawns.U2MercJapLight 220
wait 0.5
console set GoreDying ShootZone 5
wait 1.5
console hub kill 400
wait 2
shot
# 2: chest, dying (twitches)
spawn U2Pawns.U2MercJapLight 220
wait 0.5
console set GoreDying ShootZone 2
wait 0.6
shot
wait 2
shot
wait 8
shot
# 3: neck (fountain), dying
spawn U2Pawns.U2MercJapLight 220
wait 0.5
console set GoreDying ShootZone 1
wait 1.5
shot
wait 3
shot
# 4: leg (crawl), then a finishing hit while it's dying
spawn U2Pawns.U2MercJapLight 220
wait 0.5
console set GoreDying ShootZone 6
wait 3
shot
console set GoreDying ShootZone 2
wait 1
shot
dump GoreDying Taken Finished Learned
# "set" saves to U2Gore.ini: put the test values back
console set GoreDying DyingChance 0.6
console set GoreDying bLog False
quit
