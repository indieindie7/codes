# Noise-based and analytic terrain bases (the cheap layer before erosion)

Scope: what makes pure-noise/analytic heightmaps read as geological before any erosion, with formulas, parameters and URLs; how to measure it (spectral exponent, fractal dimension, geomorphon statistics); and a "good base" recipe list for a 128–256 cell NumPy pipeline. Items marked **[inference]** are my reasoning, not sourced claims. Items marked **[unverified recollection]** are details I remember from well-known code but could not re-fetch this session (Shadertoy and iquilezles.org/articles/warp returned 403/404).

## Q1. Musgrave multifractals, IQ derivative-noise, de Carpentier swiss/jordan, Elevated, uber noise — exact formulas and parameters

### Takeaway
Everything "erosion-like" in analytic noise comes from one trick: make each octave's amplitude depend on something already computed (altitude, accumulated signal, or accumulated gradient). Musgrave did it with altitude/previous-signal weights (hybrid, ridged, hetero); Quilez did it with accumulated derivatives (`1/(1+dot(d,d))`); de Carpentier added derivative-driven domain warping (swiss, jordan). Red Blob's "ridged octaves modulated by lower octaves" is the same idea in 3 lines.

### Cited Findings

**Musgrave (Texturing & Modeling, musgrave.c)**
- fBm: `value += Noise3(point) * exponent_array[i]` with `exponent_array[i] = pow(frequency, -H)`, frequency multiplied by lacunarity each octave — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c)
- Multifractal (multiplicative): `value *= offset * frequency * Noise3(point)`, value initialised to 1.0 — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c)
- Hetero_Terrain (heterogeneous): `increment = (Noise3(point) + offset) * exponent_array[i] * value; value += increment` — i.e. detail scales with current altitude (smooth valleys, rough peaks) — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c)
- HybridMultifractal: `signal = (Noise3(point) + offset) * exponent_array[i]; result += weight*signal; weight *= signal` with weight clamped to ≤1.0; recommended `H=0.25, offset=0.7` — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c); same recommended values repeated in the Blender bug report — [developer.blender.org T55284](https://developer.blender.org/T55284)
- RidgedMultifractal: `signal = abs(Noise3(point)); signal = offset - signal; signal *= signal; weight = signal*gain` (weight clamped to [0,1]), result accumulates `signal * exponent_array[i]`; recommended `H=1.0, offset=1.0, gain=2.0` — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c)
- Musgrave's own lecture notes on procedural fractal terrains (heterogeneous terrain, hybrid and ridged multifractals, motivation "smooth valleys, rough peaks") — [MusgraveTerrain00.pdf](https://www.classes.cs.uchicago.edu/archive/2015/fall/23700-1/final-project/MusgraveTerrain00.pdf)
- Reference reimplementations with the same parameter set: Blender Cycles OSL node — [node_musgrave_texture.osl](https://github.com/jesterKing/blender/blob/master/blender/intern/cycles/kernel/shaders/node_musgrave_texture.osl); SharpNoise RidgedMulti.cs — [SharpNoise](https://github.com/rthome/SharpNoise/blob/master/SharpNoise/Modules/RidgedMulti.cs)

**Inigo Quilez — fBm and noise derivatives**
- fBm definition: gain `G = 2^-H`, spectral exponent `B = 2H + 1`; most graphics code uses G = 0.5 (H = 1); IQ claims mountain profiles empirically follow about −9 dB/octave which he maps to H = 1, G = 0.5 ("higher is also wider at its base") — [iquilezles.org/articles/fbm](https://iquilezles.org/articles/fbm/)
- fBm code: `G=exp2(-H); f=1; a=1; for i: t += a*noise(f*x); f*=2; a*=G` — [iquilezles.org/articles/fbm](https://iquilezles.org/articles/fbm/)
- Analytic derivative of value noise: for `n = k0 + k1 u + k2 v + k3 w + k4 uv + k5 vw + k6 wu + k7 uvw`, `∂n/∂x = (k1 + k4 v + k6 w + k7 vw) u'(x)` with quintic `u'(x) = 30x²(x²−2x+1)` — [iquilezles.org/articles/morenoise](https://iquilezles.org/articles/morenoise/)
- fBm-with-derivatives erosion term: `a += b * n.x / (1.0 + dot(d, d))` where `d` is the running sum of octave derivatives; constants `f = 1.98` (or 2.0) frequency factor, `s = 0.49` (or 0.5) amplitude decay, initial amplitude `b = 0.5`; gives "flat areas as well as more rough areas" — [iquilezles.org/articles/morenoise](https://iquilezles.org/articles/morenoise/)
- The "Elevated" Shadertoy (MdX3Rr) uses the same `a += b*n.x/(1.0+dot(d,d))` loop; Shadertoy itself returned 403 this session, a Unity port of its source is referenced here — [Unity forum thread](https://forum.unity.com/threads/elevated-shader-in-unity3d.489054/) and a mirror listing — [boxplorer2 elevated cfg](https://github.com/charlie-x/boxplorer2/tree/master/cfgs/shadertoy/elevated)
- **[unverified recollection]** Elevated's details: rotation matrix `m2 = (0.8,-0.6; 0.6,0.8)`, per-octave `p = m2*p*2.0`, `b *= 0.5`, `SC = 250` world scale, ~16 octaves for the high-detail terrainH, ~9 for terrainM, ~3 for the low-frequency terrainL; the rotation hides grid alignment. Treat as recollection until the source is re-read.

**Giliam de Carpentier — Scape articles**
- Basic turbulence (fBm): lacunarity typically ~1.92, octaves ≈ `log(terrain_width)/log(lacunarity)`; billowy = `abs(perlin)`, ridged = `1 − abs(perlin)`; "IQ noise" = `sum += amp * n.x / (1 + dot(dsum,dsum))`; derivative of billow is `sign(f)*g`, ridged has reversed sign — [decarpentier.nl/scape-procedural-basics](https://www.decarpentier.nl/scape-procedural-basics)
- Swiss turbulence `swissTurbulence(p, seed, octaves, lacunarity=2.0, gain=0.5, warp=0.15)`: (1) ridged foundation summing `1 − abs(n.x)`; (2) accumulate `dsum` of derivatives and warp subsequent lookups toward ridges; (3) `amp *= gain * saturate(sum)` so amplitude dies in low/flat areas; (4) optional pre-warp of `p`. Described as "simulating glacial erosion patterns" — [decarpentier.nl/scape-procedural-extensions](https://www.decarpentier.nl/scape-procedural-extensions)
- Jordan turbulence `jordanTurbulence(p, seed, octaves, lacunarity=2.0, gain1=0.8, gain=0.5, warp0=0.4, warp=0.35, damp0=1.0, damp=0.8, damp_scale=1.0)`: squared noise `n2 = n*n.x` (billowed), gradient damping via `dsum_damp` (thermal-erosion look, rounded), gradient warping via `dsum_warp` (downhill gulleys, fluvial look); optional pre-warp varies peak spacing/stratification — [decarpentier.nl/scape-procedural-extensions](https://www.decarpentier.nl/scape-procedural-extensions)

**Red Blob Games — ridged octaves gated by lower octaves**
- `ridgenoise = 2*(0.5 − abs(0.5 − noise))`; `e0 = 1.0*ridge(1x); e1 = 0.5*ridge(2x)*e0; e2 = 0.25*ridge(4x)*(e0+e1)`; normalise by 1.75. Produces sharp ridges and detail only where elevation is high — [redblobgames terrain-from-noise](https://www.redblobgames.com/maps/terrain-from-noise/)
- Octave weights `[1, 0.5, 0.25, ...]` or `[1, 0.5, 0.33, 0.25, 0.2]` for more fine detail; redistribution `e = pow(e, k)` with k ≈ 3–5 (or `pow(1.2*e, 3)`) pushes middle elevations into valleys and keeps peaks steep — [redblobgames terrain-from-noise](https://www.redblobgames.com/maps/terrain-from-noise/)

**"Uber noise"**
- "Uber Noise consists of domain warping, slope erosion, altitude erosion, ridges, plateaus, terraces and other layering techniques"; sharpness blends ridge/billow (ridge offset controls peak sharpness); slope erosion = steepness used as weight that reduces small detail on steep slopes; altitude erosion = detail reduced by altitude — [Medium: A small collection of tricks for more interesting procedural terrain](https://medium.com/@tyleratstarboardgames/a-small-collection-of-tricks-for-creating-more-interesting-procedural-terrain-d9957168091b) (page returned 403 when fetched directly; the above is from the search summary, so parameter values are missing)
- Ridged-noise parameter behaviour: "ridge offset parameter directly controls peak sharpness—too high creates impossible spikes, too low flattens everything out" — [Mountains of Madness interactive](https://amanpriyanshu.github.io/The-Mountains-of-Madness/)

### Inferences
- **[inference]** The de Carpentier swiss `amp *= gain*saturate(sum)` and Musgrave hybrid `weight *= signal` are the same mechanism (altitude-gated detail); Jordan's `dsum_damp` and IQ's `1/(1+|d|²)` are the same mechanism (slope-gated detail). Swiss's `dsum`-driven warp is the only one of these that adds *lateral* structure (ridges get pulled toward each other → connected crest lines), which is why it reads most "glacial/alpine".
- **[inference]** Attribution of "uber noise" is unclear in what I could fetch; the Medium article treats it as a combination recipe rather than a single authored algorithm. The user's "Andrew Bishop?" could not be confirmed.
- **[inference]** For a 128–256 cell grid, 6–8 octaves cover the whole band (log2(256) = 8); more octaves only add sub-cell aliasing.

### Gaps
- Could not re-fetch IQ's domain-warp article (both URL variants 404) nor Shadertoy (403), so Elevated's exact constants are recollection only.
- Uber-noise exact parameter values and original author not confirmed.

## Q2. Worley/mesa, terraces/strata, domain warping, altitude/slope octave weighting, exponential noise, curl/flow, spectral synthesis with chosen β

### Takeaway
There are cheap analytic knobs for each landform class: `round(e*n)/n` for terraces, `pow(e,k)` for plain-vs-peak redistribution, ridged/billow for crests/dunes, `fbm(p + fbm(p + fbm(p)))` for folded ranges, Parberry's exponential gradient magnitudes for "mostly flat with occasional escarpments", and Saupe/Bourke inverse-FFT synthesis to hit a chosen spectral exponent exactly (β = 1.8–2.4 gives landscape-like roughness).

### Cited Findings
- Terraces: `e = round(e*n)/n`, n ≈ 2–15; "by using a function other than a step function, the terraces can be rounder or only occur at some elevations" — [redblobgames terrain-from-noise](https://www.redblobgames.com/maps/terrain-from-noise/)
- Island/mask shaping: `d = 1 − (1−nx²)(1−ny²)` (square bump) or `d = min(1,(nx²+ny²)/√2)`; `e = lerp(e, 1−d, mix)` — [redblobgames terrain-from-noise](https://www.redblobgames.com/maps/terrain-from-noise/)
- Domain warping: `f(p) = fbm(p + fbm(p + fbm(p)))`, nested so each level deforms the already-deformed space, in use since Perlin's 1984 marble — [iquilezles.org/articles/warp](https://iquilezles.org/articles/warp/) (fetch failed; description via [search summary](https://iquilezles.org/articles/warp/) and Book of Shaders which credits Quilez — [thebookofshaders.com/13](https://thebookofshaders.com/13/))
- **[unverified recollection]** IQ's reference warp code uses `q = (fbm(p+(0,0)), fbm(p+(5.2,1.3)))`, `r = (fbm(p+4q+(1.7,9.2)), fbm(p+4q+(8.3,2.8)))`, `f = fbm(p + 4r)`; the factor 4.0 is the warp strength.
- Turbulence/ridge variants (Book of Shaders): `value += amplitude*abs(snoise(st))`; ridge: `n = abs(n); n = offset − n; n = n*n` — [thebookofshaders.com/13](https://thebookofshaders.com/13/)
- Terragen "fractal warp" shader parameters: scale (size of distorting noise), warp amount, variation (lower = more chaotic), roughness 0.8–1.0 recommended for realism; strata/outcrop shaders are applied *after* erosion to restore lost detail — [planetside.co.uk terrain-techniques](https://planetside.co.uk/blog/terrain-techniques-detail-warp-erode/)
- libnoise mountain/flat composition: RidgedMulti (defaults) for mountains; Billow freq 2.0 then ScaleBias scale 0.125 bias −0.75 for flat land; Perlin (freq 0.5, persistence 0.25) as the selector; Select with edge falloff 0.125 blends them — [libnoise tutorial 5](https://libnoise.sourceforge.net/tutorials/tutorial5.html)
- Galin et al. review's noise baselines (demrepo): "Sum of 8 octaves of Simplex noises, with a lacunarity of 1/0.467 and a persistance of 0.5"; same for ridged; multifractal attenuates amplitude with "a cubic smoothstep"; warped multifractal = ridged + "domain warping using a low frequency simplex noise" — [perso.liris.cnrs.fr/eguerin/demrepo](https://perso.liris.cnrs.fr/eguerin/demrepo/); review paper itself: [Galin 2019 CGF](https://www.cs.purdue.edu/cgvlab/www/publications/Galin19CGF/) (PDF at Wiley DOI 10.1111/cgf.13657)
- Exponentially distributed noise (Parberry, JCGT 2015): statistical analysis of a 160,000 km² Utah DEM at 16 resolutions from 5 m to 164 km (octave i samples every 2^(i−1)-th point, δi = 5·2^(i−1) m; gradient = |h1−h2|/δi) finds gradients "appear to be exponentially distributed" at every octave examined (5 m–1.28 km shown) — [JCGT paper](https://jcgt.org/published/0004/02/01/paper.pdf)
- Implementation: replace Perlin's unit gradient vectors with magnitudes from an exponential distribution via inverse transform sampling; practical form is a magnitude table `m[i] = μ^i` for some 0 < μ ≤ 1 (smallest `μ^(B−1)` must be representable), gradient direction from hash `[cos h, sin h]` — [JCGT paper](https://jcgt.org/published/0004/02/01/paper.pdf); code — [Ian-Parberry/Tobler](https://github.com/Ian-Parberry/Tobler)
- Visual claim: standard Perlin has "large gradients almost everywhere, resulting in a terrain lacking in landmarks"; exponential version has "mostly flat and gently sloping terrain, with occasional areas of higher gradient that create ... cliffs and escarpments" — [JCGT paper](https://jcgt.org/published/0004/02/01/paper.pdf)
- Spectral synthesis (Saupe 1988, "The Science of Fractal Images"): fill a frequency-domain array with Gaussian-magnitude, uniform-phase coefficients, scale magnitudes by `f^(−β/2)` so power ∝ 1/f^β, inverse FFT; β = 0 white, 1 pink, 2 Brownian; Bourke's landscape examples use β = 1.8 and β = 2.4 — [paulbourke.net/fractals/noise](https://paulbourke.net/fractals/noise/); method history — [RISC fractal landscapes via FFT](https://www3.risc.jku.at/education/courses/ws2016/cas/landscape.html)
- Fast, non-simulated gully filter (Runevision 2026): gradient-aligned stripe patterns (cosine for height, sine for slope) in Worley-like randomly pivoted cells; parameters: lacunarity, detail (restricts fine gullies to steep slopes), gully weight, edge rounding (ridge vs crease), fade target −1..1 (preserve valleys vs peaks, can be driven by altitude/curvature); "stacked fading" and "straight gullies" (use sign of the sine) for branching; evaluates each point independently — [blog.runevision.com](https://blog.runevision.com/2026/03/fast-and-gorgeous-erosion-filter.html); lineage: Clay John "Eroded Terrain Noise" (2018) — [shadertoy MtGcWh](https://www.shadertoy.com/view/MtGcWh); Felix Westin "Terrain Erosion Noise" (2023) — [shadertoy 7ljcRW](https://www.shadertoy.com/view/7ljcRW); Johansen "Advanced Terrain Erosion Filter" — [shadertoy wXcfWn](https://www.shadertoy.com/view/wXcfWn)
- Slope-weighted detail: "by sampling adjacent points to figure out steepness, that steepness can be used as a weight for the effect of each layer—the steeper a point, the weaker the smaller rocky details will be" — [Medium tricks article (search summary)](https://medium.com/@tyleratstarboardgames/a-small-collection-of-tricks-for-creating-more-interesting-procedural-terrain-d9957168091b)

### Inferences
- **[inference]** Worley/Voronoi mesas: no primary source with parameters was found this session. The standard construction (F1 or F2−F1 distance, thresholded/terraced, then `min(mesa, fbm)`) is folklore; I found only generic descriptions (e.g. THREE.Terrain lists Worley as a generator — [IceCreamYou/THREE.Terrain](https://github.com/IceCreamYou/THREE.Terrain)). Treat parameters as something to tune empirically.
- **[inference]** Curl-noise drainage: I found no source using curl/flow fields for drainage approximation in heightfield synthesis; the closest cheap thing is Runevision's gradient-aligned gullies, which *are* a flow-direction field (−∇h) turned into stripes. For NumPy at 256², a one-pass D8 flow accumulation on the base is probably cheaper and more faithful than any curl trick.
- **[inference]** Exponential-gradient noise is the single analytic change most directly justified by DEM statistics (slope PDF), and it pushes toward "flat + occasional escarpment" which is also what PTRM says noise lacks (flats, valleys). It composes with everything else because it is a change inside the noise primitive.

### Gaps
- No primary source found for Voronoi mesa/plateau parameters or for curl-noise drainage; no analytic dune-field primitive found (dunes appear only as simulation; see Q3).
- IQ warp constants are recollection only (fetch 404).

## Q3. Dunes, badlands, karst, glacial U-valleys as analytic or cheap-simulation primitives

### Takeaway
The graphics literature treats dunes and glaciers as (interactive) simulations layered on a heightfield rather than analytic noise; glaciers via Shallow Ice Approximation plus procedural amplification, dunes via wind-driven sand transport with abrasion. For a hobby NumPy pipeline these are "cheap-ish" (interactive-rate GPU in the papers) but not closed-form. Analytic stand-ins are billow/ridged noise (dunes) and the Runevision gully filter (badlands).

### Cited Findings
- Desertscape Simulation (Paris, Peytavie, Guérin, Argudo, Galin, CGF 2019): interactive aeolian simulation; from a user heightfield and a time-varying high-altitude wind field, computes surface wind from relief, simulates bedrock abrasion by wind-borne sand, and dune formation; produces barchans, longitudinal and anchored dunes; brush and timeline control — [project page](https://aparis69.github.io/public_html/projects/paris2019_Deserts.html); [Wiley DOI 10.1111/cgf.13815](https://onlinelibrary.wiley.com/doi/10.1111/cgf.13815); [HAL PDF](https://hal.science/hal-02273039/file/2019-deserts.pdf)
- GPU follow-up: "Real-Time Sand Dune Simulation" (ACM 2023) extends the Desertscape sand propagation model to real time — [ACM DOI 10.1145/3585510](https://dl.acm.org/doi/10.1145/3585510)
- Glaciers (Argudo, Galin, Peytavie, Paris, Guérin, SIGGRAPH Asia / TOG 2020): Shallow Ice Approximation simulation plus procedural amplification for crevasses, moraines, seracs, ogives, icefalls; code available — [ACM DOI 10.1145/3414685.3417855](https://dl.acm.org/doi/10.1145/3414685.3417855); [oargudo/glaciers](https://github.com/oargudo/glaciers)
- Glacial erosion of terrain (U-valleys as a terrain process): "Forming Terrains by Glacial Erosion" (SIGGRAPH 2023) — [ACM DOI 10.1145/3592422](https://dl.acm.org/doi/abs/10.1145/3592422); geomorphology background on valley cross-section evolution — [arXiv 0901.1177](https://arxiv.org/pdf/0901.1177)
- Badland-like branching without simulation: Runevision gully filter (see Q2) — [blog.runevision.com](https://blog.runevision.com/2026/03/fast-and-gorgeous-erosion-filter.html)
- Real-time procedural pattern enhancement (Grenier et al., CGF 2024) adds controlled procedural detail patterns to terrain in real time — [Wiley DOI 10.1111/cgf.14992](https://onlinelibrary.wiley.com/doi/10.1111/cgf.14992)

### Inferences
- **[inference]** Dune analytic stand-in: a single-octave *anisotropic* billow (`abs(noise)` with the domain stretched 3–6× along one axis and a slight warp) plus a one-sided skew (e.g. `h = h^1.5` on the lee side via the sign of ∂h/∂x) reads as a dune field at 256². Not sourced; derived from the billow definition and the barchan asymmetry described in Paris et al.
- **[inference]** Glacial U-valley stand-in: take the drainage lines from a D8 pass, and replace the V-profile with a parabola of width proportional to accumulated area^0.5 (max of base and a parabolic trough). Not sourced beyond the general SIA literature.
- **[inference]** Karst: nothing found; Worley F1 with inverted cones (`h -= k*max(0, r0 − F1)`) is the folklore doline recipe; unsourced.

### Gaps
- No analytic/closed-form dune, karst, or U-valley primitives with parameters exist in the sources I could reach; the papers are simulations (interactive on GPU) and their parameter tables (angle of repose, wind-shadow angle, grid sizes) were not accessible from the project page.
- Peytavie "Arches" (rock) and "Terrain amplification with implicit 3D features" were not searched due to the tool budget.

## Q4. Measuring: spectral exponent / fractal dimension estimators, natural ranges, why noise fails realism tests, which tweaks move geomorphon statistics

### Takeaway
Real topography transects have S(k) ∝ k^−2 (β ≈ 2, H ≈ 0.5, D ≈ 2.5) independent of age or roughness; standard fBm with gain 0.5 has H = 1 → β = 3, which matches the user's measured 3–4 and is simply too smooth. PTRM shows noise/fBm/ridged terrains score 0.18–0.27 vs 0.66–0.86 for real terrain, because they lack valleys, ridges, summits, depressions and flats and have low geomorphon variability; valley and ridge coverage are the strongest positive predictors, slope coverage the strongest negative one.

### Cited Findings

**Spectral exponent and fractal dimension — natural ranges**
- "The power spectrum S of linear transects of the earth's topography is often observed to be a power-law function of wave number k with exponent close to −2: S(k) ∝ k^−2" over a wide range of scales — [Pelletier, "Why is topography fractal?" arXiv physics/9705033](https://arxiv.org/pdf/physics/9705033)
- Relation: β = 2H + 1 (Turcotte 1992); Matsushita & Ouchi's transect roughness exponent H ≈ 0.55 implies β ≈ 2.1; Turcotte: topography is a self-affine fractal with fractal dimension close to 2.5 — [Pelletier](https://arxiv.org/pdf/physics/9705033)
- The spectral exponent is independent of age and relief: "young, rough mountain ranges, such as the Rocky Mountains, exhibit the same power spectral exponent or fractal dimension as smooth mountain ranges such as the Appalachians"; rougher topography has larger spectral *density*, same *exponent* — [Pelletier](https://arxiv.org/pdf/physics/9705033)
- "Synthetic topography which assumes random phases in the Fourier coefficients can be generated which have S(k) ∝ k^−2 as observed in real topography" — but Pelletier's point is that this matches the spectrum while river networks additionally obey Horton/Hack/Tokunaga power laws that spectra do not capture; his advection–diffusion model reproduces both hypsometry and spectra; model slope–area exponent −0.29 to −0.32 vs observed ≈ −3/8 — [Pelletier](https://arxiv.org/pdf/physics/9705033)
- Lewis (Disney, "The case against fractals"): D = E + (3 − d)/2 for a function of Euclidean dimension E and spectrum f^−d (so for a surface E = 2: D = (7 − β)/2); fractal dimension often differs across scales; "an airport runway had a fractal dimension identical to that of some topographical data"; fractal models "appear too rough at small scales" (non-differentiable) and he recommends Markov-like spectra (κ + f)^−d or "Markaussian" autocorrelation `R(τ) = exp(−|τ|^α)`, 1 < α < 2, between Gaussian (too smooth) and Markovian (too rough) — [scribblethink.org caseagainstfractals.pdf](https://scribblethink.org/Work/caseagainstfractals.pdf)
- Relationship between D and β in computer-generated fractals studied empirically (Bies et al., Symmetry 2016) — [MDPI Symmetry 8(7):66](https://www.mdpi.com/2073-8994/8/7/66) (page returned 403; title and venue from search only)
- 1/f noise is found in "the topography of young oceanic floors and geoid undulations"; natural transects show β ≈ 2.1 — [search summary citing Bourke/Pelletier](https://paulbourke.net/fractals/noise/)
- "Multifractal Terrain Generation for Evaluating Autonomous Off-Road Ground Vehicles" (arXiv 2501.02172): uses the 3D Weierstrass–Mandelbrot function; three monofractal DEMs with D = 2.2, 2.45, 2.3–2.6 (M = 16/32/64, γ = 1.5) combined by pixel-wise product into a multifractal DEM; validated by vehicle metrics, not by realism — [arXiv 2501.02172](https://arxiv.org/html/2501.02172)

**PTRM / geomorphons — why noise fails**
- PTRM (Rajasekaran, Kang, Benes, Čadík, Galin, Guérin, Peytavie, Slavík): two user studies "showing that the synthetic terrains are perceived as lacking realism as compared to the real ones"; geomorphons (GRASS GIS r.geomorphon, 10 classes: flat, peak/summit, ridge, shoulder, spur, slope, depression/pit, valley, footslope, hollow) computed at ~200 m/pixel (each geomorphon ≈ 800×800 m²) — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610); [ACM TVCG DOI 10.1145/3514244](https://dl.acm.org/doi/10.1145/3514244)
- Scores: Real Aeolian 0.75, Real Coastal 0.77, Real Glacial 0.69, Real Fluvial 0.86, Real Slope 0.66; Synth Noise 0.24, Synth Ridged-noise 0.18, Synth fBm 0.27, Synth Thermal 0.22, Synth Fluvial 0.23, Synth Coastal 0.24 — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- "synthetic terrains do not often include geomorphological features such as depressions, summit, flat, valley, ridge, hollow and spur"; real terrains show "strong presence of valleys, ridges, and hollows" that were "not so present in the synthetic variety" — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Regression weights (influence on perception score): Valley 0.66, Ridge 0.64, Summit 0.44, Depression 0.42, Spur 0.33, Hollow 0.22, Flat −0.10, Footslope −0.15, Shoulder −0.17, Slope −0.65 (MLR, F = 153.5, p < 0.01) — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Distribution shape matters: real-terrain geomorphon fractions "tend to distribute normally with a wide span" while synthetic ones are "multi-modal and low-variability" on depression, summit, flat, valley, ridge; "lack of geomorphon diversity ... may decrease the perceived terrain realism" — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Overall ordering of class frequency in the most-realistic (real glacial) set, ascending: Depression < Summit < Flat < Valley < Ridge < Hollow < Spur < Shoulder < Slope < Footslope — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Synthetic sets were generated from noise [Perlin], ridged-noise [Musgrave], fBm surfaces, thermal, fluvial (Šťava et al.), coastal; "Eroded terrains were generated from noise-based terrains"; rendering DEMs at 512² — [arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Independent comparison (Archer, MICS 2011): Simplex noise best quality/speed among noise algorithms; hydraulic erosion best quality among erosion methods — [micsymposium.org](https://micsymposium.org/mics_2011_proceedings/mics2011_submission_30.pdf)

### Inferences
- **[inference, high confidence]** Why the user's fBm bases measure β ≈ 3–4: with gain 0.5 and lacunarity 2, H = 1 and β(1D) = 2H+1 = 3; adding `pow(e,k)` redistribution or smoothing octave caps pushes it higher. To land at β ≈ 2 (H ≈ 0.5) use gain = 2^−0.5 ≈ 0.707 per octave (with lacunarity 2), or synthesise directly with f^(−β/2) scaling and β = 2.0–2.2. **Watch the convention:** a 2D radially-averaged power spectrum of an isotropic fBm surface has exponent β2D = β1D + 1 = 2H + 2; if the realism score measures the 2D spectrum, "natural ≈ 2" would correspond to β2D ≈ 3. Check which one the pipeline computes before retuning gain.
- **[inference]** Estimator recipe for NumPy: detrend (subtract plane), apply a Hann window, `P = |fft2|²`, radially bin by |k|, fit a line to log P vs log k over roughly k ∈ [4, N/4] cells (avoid DC and the top octave where interpolation/aliasing bends the curve). Report the 1D-equivalent β = slope − 1 (if radially averaged 2D power) and D = (7 − β1D)/2 using Lewis's relation. Compare against β1D ≈ 2.0–2.2, D ≈ 2.4–2.5 (Pelletier/Turcotte). Also report the gradient PDF and test it against an exponential (Parberry): a straight line on a semi-log slope histogram.
- **[inference]** Mapping tweaks → geomorphon classes, from the class definitions (r.geomorphon ternary patterns of higher/lower neighbours): ridged noise raises *ridge* and *spur* but, used alone, produces almost no *valley* (its minima are broad, not linear) — consistent with Synth Ridged scoring lowest (0.18) in PTRM. Billow (`abs`) does the opposite: linear creases → *valley/hollow*, rounded tops → *shoulder/slope*. Derivative-damped fBm (IQ) raises *flat* and *footslope* on low ground and keeps *slope* for steep ground; Musgrave hybrid/hetero raise *flat* in valleys and *ridge/peak* up high. Domain warping does not change class fractions much on its own; it changes the spatial *variability* (wide-span distributions), which PTRM also rewards. Exponential-gradient noise raises *flat* and concentrates *slope* into bands (escarpments). None of these creates connected dendritic *valley* networks, which is why the erosion stage (or a D8/accumulation carve) remains necessary for the top-weighted class (Valley 0.66).
- **[inference]** Because *slope* has the most negative weight (−0.65) and plain fBm at β≈3 is "all slope", the single best pre-erosion move for PTRM-style scores is to introduce flats (altitude damping, terraces, exponential gradients) and linear crests/creases (ridge/billow), not to add more octaves.

### Gaps
- PTRM's numeric per-class fractions for real terrains are in the paper's supplemental material, not in the text I extracted; natural *ranges* of geomorphon fractions therefore remain unquantified here.
- Bies et al. (MDPI) page was 403; the empirical D–β deviations are not reported.
- No source directly measures how ridged/billow/warp shift geomorphon fractions; the mapping above is inference from class definitions and PTRM's per-category scores.

## Q5. Practical NumPy "good base" recipes with parameters, expected spectral exponent, and what erosion adds

### Takeaway
Build every base from one derivative-capable gradient-noise primitive (analytic or finite-difference gradients at 256² are trivial), then pick the octave-weighting rule by landform: slope-damped fBm for hills, swiss/ridged-with-altitude-gain for mountains, terraced Worley-min for mesas, anisotropic billow for dunes, FFT synthesis when a precise β is required. Target β1D ≈ 2.0–2.2 before erosion; erosion then supplies the connected valley network and slope–area scaling that no noise has.

### Cited Findings
(Parameter values below are quoted from the sources in Q1–Q4; combinations are mine.)
- fBm gain/H/β relation: `G = 2^-H`, `β = 2H + 1` — [iquilezles.org/articles/fbm](https://iquilezles.org/articles/fbm/)
- Derivative damping: `a += b*n/(1+dot(d,d))`, f = 1.98, s = 0.49, b0 = 0.5 — [iquilezles.org/articles/morenoise](https://iquilezles.org/articles/morenoise/)
- Swiss: lacunarity 2.0, gain 0.5, warp 0.15, `amp *= gain*saturate(sum)`; Jordan: gain1 0.8, gain 0.5, warp0 0.4, warp 0.35, damp0 1.0, damp 0.8, damp_scale 1.0 — [decarpentier.nl/scape-procedural-extensions](https://www.decarpentier.nl/scape-procedural-extensions)
- Musgrave hybrid H 0.25 offset 0.7; ridged H 1.0 offset 1.0 gain 2.0 — [musgrave.c](https://engineering.purdue.edu/~ebertd/texture/1stEdition/musgrave/musgrave.c)
- Redistribution `pow(e, 3–5)`, terraces `round(e*n)/n` with n 2–15, ridge `2*(0.5−|0.5−noise|)` gated by lower octaves — [redblobgames](https://www.redblobgames.com/maps/terrain-from-noise/)
- Exponential gradient magnitudes `m[i] = μ^i` via inverse-transform sampling — [JCGT Parberry](https://jcgt.org/published/0004/02/01/paper.pdf)
- FFT synthesis: magnitude `∝ f^(−β/2)`, uniform phases, inverse FFT; landscape β 1.8–2.4 — [paulbourke.net](https://paulbourke.net/fractals/noise/)
- Natural target: β1D ≈ 2, D ≈ 2.5, same exponent for young and old ranges — [Pelletier](https://arxiv.org/pdf/physics/9705033)
- What noise lacks and erosion adds: valley topology and dendritic ridge/drainage networks; "when combined at a larger scale with uplift, erosion simulations generate realistic mountain ranges with dendritic ridge networks and their dual drainage network" — [PTRM arXiv 1909.04610](https://arxiv.org/pdf/1909.04610)
- Multi-stage erosion (erode at low res, resample, erode again) gives "more pleasing and natural" branching — [planetside.co.uk](https://planetside.co.uk/blog/terrain-techniques-detail-warp-erode/)

### Inferences (recipe list — all **[inference]**, built from the cited parameters)

Common primitive: gradient (Perlin/simplex) noise `noise_d(p) -> (n, dn/dx, dn/dy)`; in NumPy at 256² use `np.gradient` on each octave if analytic derivatives are not implemented. Lacunarity 2.0 (or 1.92–1.98 to break octave alignment), 7 octaves for 256 cells, rotate the domain ~30° per octave to hide axis alignment.

1. **Rolling hills / piedmont** — IQ derivative-damped fBm: gain 0.5, `a += b*n/(1+|dsum|²)`, b0 = 0.5, f = 1.98. Then `e = pow(e_norm, 2)`. Expected β1D ≈ 3 (smooth by design; hills *should* be smooth). PTRM-relevant: raises flat/footslope, lowers slope. Erosion adds: shallow dendritic creases; keep erosion short.
2. **Alpine ridges** — de Carpentier swiss (lacunarity 2, gain 0.5, warp 0.15) with 1−|n| ridges and `amp *= gain*clip(sum,0,1)`; or Musgrave ridged (H 1, offset 1, gain 2) multiplied by a low-frequency mask so ridges only occupy highlands. Expected β1D ≈ 2.5–3 (ridging adds high-frequency power vs plain fBm; measure). Raises ridge/spur/summit; near-zero valley. Erosion adds: the valleys and the slope–area ordering; this base needs the most erosion.
3. **Rounded old range / thermally weathered** — Jordan (gain1 0.8, gain 0.5, warp0 0.4, warp 0.35, damp0 1.0, damp 0.8). Raises hollow/footslope; gullies from `dsum_warp`. Erosion adds: little; use mostly thermal.
4. **Mesas / plateaus** — low-frequency fBm `b` (gain 0.5, 3 octaves) → `t = round(b*n)/n` with n = 3–5, soften with smoothstep width 0.05; mask by Worley F1 cells (`cell = smoothstep(r0, r0+w, F1)`) so each plateau has its own level; `h = min(t_cell, fbm_detail*0.2 + t_cell)`; cliffs come from the step edges. Expected β1D low inside plateaus, spectrum dominated by the step edges (flat-ish, then a k^−2 edge spectrum) — measure. Raises flat/shoulder strongly; erosion adds: talus aprons and badland gullies at the cliff feet (Runevision-style gully filter is a good cheap substitute).
5. **Dune field** — single-octave anisotropic billow: `n = |noise(x*1, y*4)|` (stretch 3–6× along the wind), small warp `p += 0.1*fbm(p)`, lee-side skew `h = where(dh/dx<0, h**1.5, h)`, plus 2 fine octaves at gain 0.3 for ripples. Not from the dune-simulation papers (those are wind-transport simulations); this is a stand-in. Erosion: none, or a few avalanching (angle-of-repose) passes only.
6. **Flat basin with escarpments** — Parberry exponential-gradient Perlin: gradient magnitudes `μ^i` with μ ≈ 0.9 over a table of 256 entries (values tuned, source gives the table form not μ), direction from hash; 6 octaves, gain 0.5. Raises flat; slope concentrated into bands. Erosion adds: incision below escarpments.
7. **Exact-β control** — Saupe/Bourke synthesis: `A(k) = N(0,1)*|k|^(−β/2) * e^{iφ}`, φ uniform, zero DC, `ifft2` real part; β1D target 2.0–2.2 ⇒ with the 2D-spectrum convention use exponent β2D = β1D + 1 ≈ 3.0–3.2 on `|k|` (i.e. amplitude `|k|^(−(β1D+1)/2)`). Use it as the *large-scale* term, then multiply detail octaves by the slope/altitude gates above. Erosion adds everything structural; this base is pure statistics.
8. **Folded range** — domain warp `h = base(p + 4·W(p))` with `W = (fbm(p+(5.2,1.3)), fbm(p+(1.7,9.2)))`, strength 4.0 at unit-domain scale (constants are recollection of IQ's article), applied to the swiss or ridged base; raises spatial variability of geomorphons, not class fractions.

Measurement checklist for each base (all **[inference]**): β1D via radial spectrum slope −1; D = (7 − β1D)/2; slope-PDF semilog linearity (exponential test); geomorphon fractions via a ternary-pattern implementation (flat/ridge/valley/slope at minimum); PTRM-like score = Σ w_c·frac_c with the regression weights above (0.66 valley, 0.64 ridge, 0.44 summit, 0.42 depression, 0.33 spur, 0.22 hollow, −0.10 flat, −0.15 foot, −0.17 shoulder, −0.65 slope). Note PTRM's weights were fit at 200 m/pixel on 512² DEMs; at 128–256 cells the neighbourhood radius must be rescaled and absolute scores will not be comparable, only rankings.
